# 自衛隊ブラウザー検索：接続前の実装

利用者の「Cloudflareの追加・接続は後で、それ以外の設定を完了」に対応。
この変更は保存版。公開・本番の接続設定は本作業では実行していない。

## 実装

- 官公需情報ポータルのAPI検索を維持。自衛隊の3区分は別の `/api/browser-search` で処理し、官公需への代替検索は行わない。
- 陸自20部隊・機関、海自3区分、空自28機関の指定リンクを、公式の入口ページの表示名から解決する。類似名を部分一致で選ばず、一意に確認できない対象は未確認として表示。
- Cloudflare Browser Run `/content` でJavaScript実行後のHTMLを取得し、公式リンクを順番に辿る。呼出先と取得先はサーバー側で固定・制限。HTML・表・公告PDFをルールで解析する。AIの呼出しはない。
- 1リクエスト1ページ。画面が開いている間に順次処理し、閉じた場合は保存済み進捗から手動再開。定期実行や画面を閉じた後の継続実行ではない。
- 確認先を順番に回り、大きいサイトだけで他の対象が後回しにならないようにする。1検索300ページ、確認先ごと30ページ、深さ5、待機600ページ、一覧最大100件。上限・未確認を表示。
- 3つのタブに開始・一時停止・再開、各確認先の進捗、成功・失敗・一部取得・未確認を表示。確認済みの結果から既存の一覧へ反映。
- D1に利用者・タブ・検索先ごとに直近1検索を保存。原子的なリースで二重処理を抑制。停止や新規検索後に古い通信が結果を上書きしない。
- DB変更は追加マイグレーション `0002_worthless_shooting_star.sql` のみ。既存テーブルの変更・削除なし。
- 本文・表の提出締切を確認し、検索日の翌日以降だけ表示。検索日を跨いだ再開は停止し、新しい検索を案内。入札日時・開札日・参加申込期限・納期は代用しない。表の和暦略記はページの明確な和暦記載と照合。
- 画像PDFや取得できない資料、期限不明は対象外。アクセス検証画面は取得失敗。0件という意味に置き換えない。
- 既存の都道府県・種別管理・案件先機関名・案件先URL・提出期限・Larkへ登録の一覧形式を使用。原文で判定できない都道府県等を創作しない。機関名は辿った機関リンクから得るが、海自の「公告」のような区分名しか分からない場合は空欄／要確認。
- Lark登録は既存のボタン操作で実行。自動書込み・Baseのフィールド変更・自動化の再作成なし。

## 接続時に残る作業

Cloudflareプラグインの接続と、ポータルが検索を実行するための認証情報は別。後日、対象アカウントを確認し、Sitesのサーバー側秘密情報に以下を設定する。

| 変数 | 内容 |
|---|---|
| CLOUDFLARE_BROWSER_ACCOUNT_ID | 対象CloudflareアカウントのID |
| CLOUDFLARE_BROWSER_API_TOKEN | 対象アカウント限定の Browser Rendering / Edit 権限 |

値をフロントエンドやリポジトリへ保存しない。`.env.example` は空欄の設定名のみ。アプリの設定確認は値を返さず、設定有無だけ返す。設定値があることと実際の接続成功は区別して画面に表示する。

本番環境で未解決だったSitesの認証ヘッダー受渡し（ユーザーIDが届かず401になる件）も、公開後のログイン確認が必要。メールアドレスだけを信用するような認証変更は加えていない。

公開時には新規マイグレーションを含めて反映。その後、ログイン、Cloudflareの権限・利用枠、陸海空の各入口、指定先・PDFへのアクセス、実際の結果一覧、停止・再開を確認する。Cloudflareに接続しても防衛省側のアクセス検証を通過できる保証はない。検証画面を回避する実装はない。

## 検証結果

接続なしの自動テスト33項目が成功。最終のSites用ビルドも成功し、新しいAPI経路を含むWorker出力を作成。

補助的な `tsc --noEmit` は既存プロジェクトにCloudflareのランタイム型宣言がないため完走していない。新しいPDF呼出しで検出した型の不一致は修正済み。Wranglerによる型生成はリモート設定の接続要求で中断されたため、環境の型宣言は今回追加していない。

- 3タブ×3区分の9組合せで20/3/28対象すべてのリンク解決・順次取得を、テスト用HTMLで確認。
- 9組合せの結果が既存のLark対応一覧に表示されることをサーバーレンダリングで確認。
- 表の列結合、和暦、提出締切と他の日付の区別、キーワードOR、HTML公告・添付PDFの追跡、当日・期限切れ・不明期限の除外を確認。
- 実際のPDF抽出ライブラリでテストPDFの文字を読取り。日本語の実公告や画像PDFを読めたという結果ではない。
- SQLiteで本番と同じSQLを実行し、利用者分離・保存・リース・停止・古い処理の書戻し拒否を確認。
- 接続済み相当のテスト用応答でAPIの開始→1ページ処理→再読込→一時停止を確認。
- 未接続・未ログイン時は外部呼出しなし。Cloudflare側の認証・利用枠のエラー、外部URLや大容量資料の拒否を確認。
- 既存の官公需API検索・取得量超過時の絞込み・締切・表示の回帰テストが成功。

実サイトの自衛隊9パターンは未検証。本番の21パターンすべてが成功した、という報告ではない。実際のアクセスと取得精度は接続後に確認する。
